## 1. Обзор продукта

### 1.1 Название
**Focus Garden** — приложение для управления фокусом и продуктивностью с элементами геймификации.

### 1.2 Концепция
Focus Garden — это кроссплатформенное приложение (Web + iOS), которое превращает технику Pomodoro в увлекательный процесс выращивания виртуального сада. За каждый завершённый фокус-сеанс пользователь получает деревья, облака и открывает животных, формируя уникальный визуальный ландшафт своей продуктивности.

### 1.3 Проблема
Людям сложно поддерживать фокус в мире постоянных отвлечений. Существующие таймеры Pomodoro функциональны, но скучны — пользователи быстро теряют мотивацию и бросают практику. Нет ощутимого визуального вознаграждения за усилия по концентрации.

### 1.4 Решение
Focus Garden делает процесс концентрации визуально вознаграждающим. Пользователь видит, как его сад растёт с каждым завершённым сеансом, что создаёт долгосрочную мотивацию. Спокойная эстетика и милые животные-достижения формируют эмоциональную привязанность к продукту.

### 1.5 Ключевое ценностное предложение
> «Каждая минута фокуса — это семя, из которого вырастает ваш сад продуктивности»

## 3. Функциональные требования

### 3.1 Таймер Pomodoro (Ядро продукта)

#### 3.1.1 Режимы таймера
| Режим | Длительность по умолчанию | Диапазон настройки | Цвет |
|-------|--------------------------|-------------------|------|
| Фокус | 25 минут | 5–60 минут (шаг 5) | Зелёный (#9ed9c5) |
| Короткий перерыв | 5 минут | 1–15 минут (шаг 1) | Голубой (#a8c5e0) |
| Длинный перерыв | 15 минут | 5–30 минут (шаг 5) | Фиолетовый (#d4a5c8) |

#### 3.1.2 Поведение таймера
- Циклы: после 4 фокус-сеансов автоматически переключается на длинный перерыв
- Отображение: круговой прогресс-бар (SVG) с обратным отсчётом
- Управление: запуск/пауза, сброс
- Счётчик текущего цикла
- Звуковое уведомление при завершении (настраиваемое вкл/выкл)
- **[iOS]** Фоновая работа таймера (Background Execution)
- **[iOS]** Локальные Push-уведомления о завершении
- **[iOS]** Live Activity (iOS 16.1+) — отображение таймера на экране блокировки
- **[iOS]** Тактильная обратная связь (Haptics)

### 3.2 Виртуальный сад (Геймификация)

#### 3.2.1 Элементы сада
| Элемент | Условие получения | Максимум на экране |
|---------|------------------|-------------------|
| Дерево | 1 за каждый завершённый Pomodoro | 12 (с перспективным масштабированием) |
| Облако | 1 за каждые 2 Pomodoro | 8 (с анимацией парения) |
| Животное | Разблокируется при достижении milestone | По 1 каждого типа |

#### 3.2.2 Животные-достижения (Milestones)
| Животное | Milestone (Pomodoros) | Визуальный стиль |
|----------|----------------------|------------------|
| Бабочка | 3 | Анимация крыльев |
| Птица | 7 | Сидит на дереве |
| Кролик | 15 | На лужайке |
| Олень | 25 | На переднем плане |
| Лиса | 40 | В центре сада |

#### 3.2.3 Анимации
- Spring-анимации появления новых элементов
- Парящие облака с плавным движением
- Лёгкое покачивание деревьев
- Пустое состояние: «Your garden awaits» с призывом к действию

### 3.3 Статистика и аналитика

#### 3.3.1 Ключевые метрики
- Всего Pomodoro за всё время
- Общее время фокуса (часы)
- Прогресс за неделю
- Среднее количество Pomodoro в день

#### 3.3.2 Визуализация
- **Area Chart**: активность за неделю/месяц/всё время (Recharts на Web, Charts framework на iOS)
- **Activity Calendar**: тепловая карта активности за 90 дней (по аналогии с GitHub)
  - Интенсивность цвета: прогрессивное затемнение (0–8+ Pomodoro)
  - Тултипы с датой и количеством при наведении
- **Achievement Cards**: лучший день, текущий streak, всего активных дней

#### 3.3.3 Трекер прогресса
- Текущий streak (серия дней) с иконкой огня
- Pomodoro сегодня с иконкой цели
- Всего за всё время с иконкой трофея
- Список достижений (5 животных) со статусом разблокировки

### 3.4 Настройки

#### 3.4.1 Настройки таймера
- Слайдеры длительности (фокус, короткий перерыв, длинный перерыв)
- Переключатель звука завершения
- Информационная карточка о технике Pomodoro

#### 3.4.2 Настройки приложения [iOS]
- Выбор языка (английский / русский)
- Тёмная тема (автоматическая / ручная)
- iCloud синхронизация (вкл/выкл)
- Резервное копирование данных
- Ежедневные сводки (уведомления)

### 3.5 Локализация
- **Поддерживаемые языки:** английский, русский
- **[iOS]** Полная локализация через .lproj бандлы
- **[Web]** Частичная локализация (русские подписи в UI статистики)

### 5.3 Архитектура данных

#### Модели данных (единые для обеих платформ)

```
TimerSettings {
  focusTime: number          // минуты (по умолчанию 25)
  breakTime: number          // минуты (по умолчанию 5)
  longBreakTime: number      // минуты (по умолчанию 15)
  soundEnabled: boolean      // по умолчанию true
}

DailyRecord {
  date: string               // ISO-формат даты
  pomodoros: number           // кол-во за день
  focusMinutes: number        // общее время фокуса
}

Progress {
  totalPomodoros: number      // всего за всё время
  todayPomodoros: number      // за сегодня
  currentStreak: number       // текущая серия дней
  trees: number               // количество деревьев
  clouds: number              // количество облаков
  animals: string[]           // ['butterfly', 'bird', ...]
  history: DailyRecord[]      // история по дням
}
```

#### Стратегия хранения данных
| Платформа | Механизм | Ключи |
|-----------|---------|-------|
| Web | localStorage | `focusGardenSettings`, `focusGardenProgress`, `focusGardenLastDate` |
| iOS | UserDefaults | Аналогичные ключи через StorageManager |
| iOS (облако) | CloudKit | Опциональная синхронизация через iCloud |

## 10. Конкурентный анализ

| Приложение | Плюсы | Минусы | Отличие Focus Garden |
|------------|-------|--------|---------------------|
| **Forest** | Большая база пользователей, реальные деревья | Платное, перегружено рекламой в free-версии | Более спокойная эстетика, Web + iOS, бесплатный базовый функционал |
| **Flora** | Красивый дизайн, социальные фичи | Только мобильные платформы | Кросс-платформа, открытый web-доступ |
| **Focusmate** | Живые сессии с людьми | Требует камеру, социальное давление | Одиночный опыт, нет необходимости в камере |
| **Be Focused** | Простой и надёжный | Устаревший дизайн, нет геймификации | Современный дизайн, виртуальный сад |
| **Tide** | Красивые звуки природы | Слабая геймификация | Глубокая система прогрессии и достижений |

### Конкурентные преимущества Focus Garden
1. **Кросс-платформенность** — Web + iOS (в будущем Android)
2. **Бесплатный полный функционал** — без ограничений на базовые фичи
3. **Спокойная эстетика** — не pressure-driven, а reward-driven
4. **Приватность** — данные хранятся локально, без регистрации
5. **Открытость** — open-source ядро, community-driven развитие

## 11. Риски и ограничения

### 11.1 Технические риски
| Риск | Вероятность | Влияние | Митигация |
|------|------------|---------|-----------|
| Потеря данных при очистке localStorage (Web) | Средняя | Высокое | PWA с IndexedDB, экспорт/импорт данных |
| Несовместимость таймера в background на iOS | Низкая | Высокое | Fallback на уведомления, тестирование на реальных устройствах |
| Рассинхронизация данных iCloud | Средняя | Среднее | Конфликт-резолюшн стратегия, ручной бэкап |
| Отказ Apple при ревью App Store | Средняя | Высокое | Соблюдение Human Interface Guidelines, подготовка к апелляции |

### 11.2 Продуктовые риски
| Риск | Вероятность | Влияние | Митигация |
|------|------------|---------|-----------|
| Низкий retention после первой недели | Высокая | Высокое | Streak-механика, daily rewards, уведомления-напоминания |
| Слабая конверсия в Pro | Средняя | Среднее | A/B тестирование paywall, ценностный премиум-контент |
| Конкуренция с Forest | Высокая | Среднее | Фокус на Web + бесплатность + приватность |

## 13. Приложения

### 13.1 User Stories

**Как студент**, я хочу запустить фокус-таймер на 25 минут, чтобы сконцентрироваться на учёбе без отвлечений.

**Как пользователь**, я хочу видеть, как мой сад растёт после каждого завершённого сеанса, чтобы чувствовать прогресс.

**Как пользователь**, я хочу настроить длительность фокуса и перерывов под свой ритм работы.

**Как пользователь**, я хочу видеть статистику за неделю/месяц, чтобы понимать свои паттерны продуктивности.

**Как пользователь iOS**, я хочу получать уведомление о завершении таймера, даже если приложение свёрнуто.

**Как пользователь**, я хочу видеть streak (серию дней), чтобы не разрывать цепочку продуктивных дней.

**Как пользователь**, я хочу разблокировать новых животных при достижении milestones, чтобы иметь долгосрочные цели.

**Как пользователь iOS**, я хочу синхронизировать данные через iCloud, чтобы не потерять прогресс при смене устройства.

### 13.2 Глоссарий
| Термин | Определение |
|--------|-------------|
| **Pomodoro** | Единица фокус-сеанса (по умолчанию 25 минут) |
| **Streak** | Непрерывная серия дней с хотя бы одним завершённым Pomodoro |
| **Milestone** | Целевое количество Pomodoro для разблокировки достижения |
| **Garden** | Виртуальное пространство, визуализирующее прогресс пользователя |
| **Live Activity** | Виджет iOS, отображающий таймер на экране блокировки |
| **Freemium** | Бизнес-модель: базовый функционал бесплатно, расширенный — по подписке |
