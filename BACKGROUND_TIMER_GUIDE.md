# Background Timer & Notifications - Implementation Guide

## Обзор изменений

Реализована полная поддержка работы таймера в фоновом режиме с push-уведомлениями.

---

## ✅ Исправленные баги

### 1. **Streak Calculation Bug (AppViewModel.swift:60-70)**
**Проблема:** Серия дней увеличивалась при каждом завершенном помодоро в течение дня
**Решение:** Серия теперь обновляется только один раз в день при первом завершенном помодоро

### 2. **Timer не работает в фоне**
**Проблема:** При блокировке экрана Timer останавливался
**Решение:** Реализован расчет на основе endTime вместо countdown

### 3. **Отсутствие уведомлений**
**Проблема:** Не было push-уведомлений при завершении таймера
**Решение:** Добавлен NotificationManager с локальными уведомлениями

## 🔧 Как это работает

### Таймер в фоновом режиме

1. **При запуске таймера:**
   - Вычисляется `endTime = Date() + timeLeft`
   - Планируется локальное уведомление на момент `endTime`
   - Сохраняется состояние в UserDefaults

2. **При переходе в фон:**
   - Сохраняются: endTime, mode, completedCycles
   - Timer продолжает работать в background (до ~3 минут в iOS)
   - Уведомление гарантирует срабатывание даже если app suspended

3. **При возвращении в приложение:**
   - Вычисляется оставшееся время: `remainingTime = endTime - Date()`
   - Если время истекло → вызывается `handleTimerComplete()`
   - Если время осталось → обновляется UI

4. **При полном закрытии и перезапуске:**
   - `restoreTimerIfNeeded()` проверяет UserDefaults
   - Восстанавливает состояние, если таймер все еще активен
   - Очищает данные, если таймер истек

### Push-уведомления

**Типы уведомлений:**
- 🎉 "Focus Session Complete! Great work! Time for a break."
- 💪 "Break Complete! Ready to get back to work?"
- ✨ "Long Break Complete! Feeling refreshed? Let's continue!"

## 🧪 Тестирование

### Сценарий 1: Блокировка экрана
1. Запустите таймер (например, 2 минуты)
2. Заблокируйте экран (Power button)
3. Подождите 2 минуты
4. **Ожидаемый результат:**
   - Появится push-уведомление
   - Прозвучит звук (если включен)
   - Разблокировка покажет переключение режима

### Сценарий 2: Переход в другое приложение
1. Запустите таймер (25 минут Focus)
2. Откройте другое приложение (Safari, Messages и т.д.)
3. Подождите окончания таймера
4. **Ожидаемый результат:**
   - Push-уведомление появится вовремя
   - При возврате в FocusGarden таймер автоматически переключится на Break

### Сценарий 3: Полное закрытие приложения
1. Запустите таймер (10 минут)
2. Свайпните приложение вверх из App Switcher (полное закрытие)
3. Подождите 5 минут
4. Откройте приложение снова
5. **Ожидаемый результат:**
   - Таймер продолжает работать
   - Показывает правильное оставшееся время (5 минут)
   - При истечении сработает уведомление

### Сценарий 4: Проверка streak
1. Завершите 3 помодоро в один день
2. Проверьте streak в статистике
3. **Ожидаемый результат:**
   - Streak увеличился только на 1
   - Today's pomodoros = 3

### Сценарий 5: Восстановление после перезагрузки
1. Запустите таймер
2. Полностью закройте приложение
3. Перезагрузите iPhone
4. Откройте приложение
5. **Ожидаемый результат:**
   - Таймер восстановится, если время еще не истекло
   - Или очистится, если время истекло

## 🐛 Известные ограничения iOS

1. **Background execution time:** iOS дает ~3 минуты для фоновой работы
   - Решение: используем локальные уведомления (работают всегда)

2. **Low Power Mode:** Уведомления могут задерживаться
   - Решение: нет, это ограничение iOS

3. **Do Not Disturb:** Уведомления будут тихими
   - Решение: нет, это настройка пользователя

## 📚 Техническая документация

### UserDefaults Keys:
- `timerEndTime` (TimeInterval) - время окончания таймера
- `timerMode` (String) - текущий режим ("Focus Time" / "Short Break" / "Long Break")
- `timerCompletedCycles` (Int) - количество завершенных циклов

### Notification Identifier:
- `timer_completion` - ID для локального уведомления

### Audio Session:
- Category: `.playback`
- Options: `.mixWithOthers`
- Mode: `.default`
